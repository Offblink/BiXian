# decide — 一条命令换一个判断

给**不需要文字输出**的判断用：是/否、N 选一、有序打分。它不推理、不解释、不写字，只回一个判断和概率 —— 比让主模型写一段推理再从里面挑答案**更快、更稳、更便宜**，而且**每次都留痕**。

## 什么时候用

- 二值闸门：这一步该不该继续、这条命令安不安全、这个文件要不要动。
- 路由：这句话属于哪一类、该叫哪个工具。
- N 选一：界面/文本里挑一个目标。
- 打分：这条记忆跟当前任务相关吗。

## 什么时候**不**用

- 需要解释、需要多步推理、需要写文字 → 找主模型。
- **不可逆动作**（发布、删除、付款、发消息）→ 只能用 `--policy irreversible` **做闸门**，最终必须人去确认。

## 三条命令

```bash
# 是/否：退出码就是答案（0=YES 1=NO 2=拿不到判断）
decide noul "<state 描述>" "<问题>" [--policy <动作类别>] [--origin trusted|untrusted]

# N 选一：stdout 是选中的标签；--index 给 1-based 序号
decide choice "<state 描述>" "<问题>" --options 保存,另存为,打印

# 有序打分：stdout 是 "<分数>\t<标签>"（分数是连续的）；--index 给 0 基桶号
decide score "<state 描述>" "<问题>" --levels 无关,弱相关,相关,强相关
```

```bash
decide selftest    # 一行证明服务接上了（url / model / 温度 / 延迟 / 一个概率）
decide spec        # 权威契约（HTTP 形状、字段、退出码、策略与审计 schema）
decide ask         # 原始请求走 stdin、原始 JSON 出（一次问 N 个，摊销启动开销）
```

**`state` 必须自足**：它不知道你的项目、你的偏好、上一轮聊了什么。谁写 state，谁决定了判断质量。

## 退出码（**不解析输出也能用**）

| 码 | 含义 | 你该做什么 |
|---|---|---|
| `0` | YES / 得到答案 | 照做 |
| `1` | NO | 停下或换路 |
| `2` | **UNDECIDED** | **当成"没判断"，回退到你自己的模型；绝不猜** |

`2` 的来源：服务没起、超时、形状不对、**分布是平的**（没有信号）、或**概率没过策略阈值**。
stdout **永远只有一行**；要细节加 `--json`（含 `on_fail`，告诉你策略要求失败时怎么办）；原因写到 stderr。

## 策略（阈值属于你的调用点）

```bash
decide noul "<state>" "<问题>" --policy run_command          # 按动作类别取阈值
decide noul "<state>" "<问题>" --threshold 0.87             # 或直接给边界
```

| 策略 | 阈值 | 用途 |
|---|---|---|
| `explore` | 0.20 | 宁可误报，先筛一遍 |
| `default` | 0.50 | 普通闸门 |
| `irreversible` | 0.99 | 不可逆动作前的闸门 |
| **未声明的类别** | **当 `irreversible`** | 白名单式：忘了声明只会多问人，不会放开 |

- 概率过了普通边界但没到该策略要求 → **UNDECIDED（2），不是 NO**："不够自信"和"否"是两件事。
- **`choice` 的闸门看最高概率**（`--json` 里的 `peak`），**不是** `confidence`（那是 top1−top2 的间隔）。
- **不可逆动作必须 `--origin trusted`**：`state` 里混着不可信文本（文件内容、网页、别人发的消息）时会被**直接拒绝（2），且什么都不发出去**。因为决策层的输入不可信、输出却是"放行/拦截"，攻击者能把答案写进输入里。

## 接不上怎么办

- 退出码 `2` → 回退，不要重试三次然后卡住（`--timeout` 默认 3 秒）。
- 先 `decide selftest`：一行就能证明后端在不在。
- 同输入同答案（本地缓存），重试安全但无意义。
- **这条命令失败不许让整个任务失败。**

## 没装 Python / 不想装脚本：curl 一行

```bash
curl -s http://127.0.0.1:8009/v1/systemone -H 'content-type: application/json' \
  -d '{"state":"<描述>","questions":{"q":{"type":"noul","instructions":"<问题>"}}}'
# -> {"model":"…","answers":{"q":{"type":"noul","noul":0.83}},"usage":{…},"latency_ms":…}
```

`"noul"` 就是 P(是)，自己跟阈值比。这是**只有 HTTP 工具、没有 shell** 的 agent 的兜底面。

## 装法（四种投递，同一份内容）

1. 支持技能的 harness：把这个目录放进它的技能目录；
2. 能读文件：把本文件路径告诉 agent；
3. 只能发文本：人把本文件当系统提示词粘进去；
4. 非 LLM 自动化：直接把 `decide` 当命令跑（`pip install -e .` 后有 `decide`；没安装就用 `python <repo>/bin/decide.py`）。

## 观感提示

它**不是笔仙**：一次前向 + 读候选标签的概率 + 一个拟合温度；同输入同答案；错了看得出来（概率可校准检验）。
它**也不会替 agent 思考**：窄、重复、错也便宜的判断交它；需要世界知识或长文推理的，交回主模型。
